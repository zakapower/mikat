# Микат — редизайн popup (Lucide, настройки, автогео, иконка)

Дата: 2026-08-13  
Статус: утверждено в диалоге («делай»)

## Цель

Привести popup к уровню соседних MV3-расширений: иконки Lucide, нормальный переключатель темы, второй экран настроек, автогео при первом запуске, читаемая иконка приложения.

## Решения

| Тема | Решение |
|------|---------|
| Навигация | Два view в одном popup: `main` / `settings` |
| Тема | Icon-кнопка Sun/Moon в шапке главного |
| Настройки | Кнопка Settings → второй экран с ArrowLeft «назад» |
| Локация на главном | MapPin + адрес + компактная Locate (обновить гео) |
| Локация в настройках | Полный блок: гео-кнопка, поиск города, результаты |
| Метод / аср / уведомления | Только в настройках |
| Первый запуск | Автозапрос геолокации → расписание; при отказе → settings |
| Lucide | Vendored SVG локально (без CDN/бандлера) |
| Иконка приложения | Полумесяц на фиолетовом скруглённом квадрате, 16/48/128, без цифры |

## UI

### Главный (`data-view="main"`)

1. Шапка: бренд «Микат» | theme toggle | settings  
2. Следующий намаз + countdown (Clock)  
3. Список намазов  
4. Низ: MapPin + короткий адрес + Locate  

### Настройки (`data-view="settings"`)

1. Шапка: ArrowLeft + «Настройки»  
2. Локация: label, «Моё местоположение», поиск, результаты  
3. Метод, аср, уведомления, «напомнить за»  
4. Status-строка ошибок/прогресса может быть общей  

### Иконки Lucide

`Sun`, `Moon`, `Settings`, `ArrowLeft`, `Clock`, `MapPin`, `Locate`, `Search`, `Bell` — цвет `currentColor`, ~18–20px в UI, кнопки управления 32×32.

## Автогео

При `boot()`, если `settings.coords == null`: статус «Определяю местоположение…», `getCurrentCoords` + optional reverse label, `persist`. Успех → main + расписание. Ошибка/отказ → `data-view="settings"` + сообщение. Повторные запуски с coords — без автозапроса.

## Иконка приложения

Плоский знак: градиент `#3b1d6e` → `#6d28d9`, светлый полумесяц, без глоу и без «24». Файлы: `icons/icon16.png`, `icon48.png`, `icon128.png`.

## Вне scope

- Отдельная `options.html`
- Бандлер / npm lucide
- Смена визуального accent с фиолетового
- Firefox

## Критерии готовности

1. На главном нет длинных форм локации/метода — только pin/адрес/locate и расписание.  
2. Тема — иконка Sun/Moon, не текстовая кнопка.  
3. Settings открывает второй экран; назад возвращает на main.  
4. Первый запуск без coords пытается автогео.  
5. Lucide-иконки локальные.  
6. Новые PNG иконок приложения на месте старых.

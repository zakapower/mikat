# Микат — дизайн расширения времён намаза

Дата: 2026-08-13  
Статус: утверждено в диалоге, ожидает ревью файла перед планом реализации

## Цель

Chrome/Edge (Manifest V3) расширение **Микат**, которое показывает времена намаза для текущей локации, countdown до следующего намаза в popup и на badge иконки, с опциональными уведомлениями.

Папка проекта: `Новая папка` → переименовать в `mikat`.

## Решения (зафиксировано)

| Тема | Решение |
|------|---------|
| Название | Микат |
| Браузер | Chrome / Edge, Manifest V3 |
| Локация | Геолокация + ручной поиск города (fallback) |
| Расчёт | Локально (библиотека adhan), не API на каждый день |
| Метод | Выбор в настройках, по умолчанию Muslim World League |
| Уведомления | Есть, можно полностью выключить |
| Badge | Countdown до следующего намаза на иконке |
| Стиль | Как у соседних проектов (CSS-переменные, light/dark, wash-градиент), акцент фиолетовый |

## Подход

Локальный расчёт времён + сетевой геокодинг только для поиска города. Service worker планирует alarms и обновляет badge. Popup — лёгкий UI без тяжёлого фреймворка.

Альтернативы отклонены: полный Aladhan API (сеть/офлайн), тяжёлый React/Vite UI (избыточно для popup).

## Архитектура

```
mikat/
  manifest.json
  background.js          # SW: расчёт, alarms, badge, notifications
  popup/
    popup.html
    popup.css
    popup.js
  lib/
    prayer.js            # обёртка adhan
    geo.js               # geolocation + Nominatim search
    storage.js           # chrome.storage
    badge.js             # формат текста badge / title
  vendor/                # adhan (бандл)
  icons/
  docs/superpowers/specs/
```

### Permissions

- `storage` — настройки и кэш суток
- `alarms` — пересчёт, badge, уведомления
- `notifications` — оповещения о намазе
- `geolocation` — координаты пользователя
- host permission для Nominatim (поиск города); запросы с корректным `User-Agent` / идентификатором приложения Микат

### Поток данных

1. SW при установке / старте / раз в минуту: читает settings + coords → считает времена на сегодня (и завтра для перехода через полночь) → обновляет badge и title → ставит alarms на намазы (и pre-notify).
2. Popup открывается: читает кэш из storage, сразу рисует UI; при необходимости уточняет геолокацию / пересчитывает.
3. Смена города / метода / уведомлений → запись в storage → сообщение SW → пересчёт.

### Модули

| Модуль | Ответственность | Зависимости |
|--------|-----------------|-------------|
| `prayer.js` | Времена Фаджр…Иша + sunrise, next prayer | adhan, settings |
| `geo.js` | getCurrentPosition, searchCities, reverse label | Nominatim, permissions |
| `storage.js` | get/set settings, day cache | chrome.storage |
| `badge.js` | формат `42м` / `2ч` / короткий маркер «сейчас» | — |
| `background.js` | orchestration | все lib |
| `popup.js` | UI, формы настроек | storage, geo, prayer |

## UI

Ширина popup ~360px, высота ~520px. Один столбец.

1. **Шапка:** бренд «Микат», переключатель темы.
2. **Следующий намаз:** имя, время, крупный countdown.
3. **Список:** Фаджр, Восход, Зухр, Аср, Магриб, Иша; следующий/текущий — accent.
4. **Локация:** название города; «Моё местоположение»; поле поиска.
5. **Настройки:** метод расчёта; мазхаб Аср (стандарт / ханафи); уведомления on/off; за сколько минут (5 / 10 / 15).

### Визуальный язык

Как `islam-answers` / `quran-hadith` / `lokach`:

- Переменные: `--bg`, `--wash`, `--surface`, `--ink`, `--muted`, `--line`, `--accent`, `--on-accent`
- Light/dark через `data-theme`
- Фон: radial wash-градиент + `--bg`
- Display + sans типографика
- Акцент: light `#6d28d9`, dark `#a78bfa`; `--on-accent` контрастный к фиолетовому
- Без «карточного дашборда»; спокойные отступы; hover только для мыши (как у соседей)

Язык UI: русский.

## Badge и уведомления

### Badge

- Обновление не реже раза в минуту через `chrome.alarms`.
- Текст: `<N>м` если < 60 мин; `<N>ч` если ≥ 60 мин; около наступления — короткий маркер (например `·`).
- `chrome.action.setTitle`: «{Намаз} через {N} мин · {Город}».
- Работает независимо от уведомлений.

### Уведомления

- Alarms на каждый намаз и опционально за N минут (если включено).
- Полный выключатель в настройках.
- Клик по уведомлению пытается открыть popup (`chrome.action.openPopup` где доступно); иначе обновляет badge/title без отдельного окна.

## Данные и ошибки

### Хранение

`chrome.storage.sync` — настройки:  
`theme`, `method`, `asrMadhab`, `notificationsEnabled`, `notifyBeforeMinutes`, `coords`, `placeLabel`.

`chrome.storage.local` — кэш времён на дату + next prayer snapshot для мгновенного popup/badge.

### Ошибки

| Ситуация | Поведение |
|----------|-----------|
| Геолокация отклонена | Форма поиска города, без блокировки UI |
| Нет сети при поиске | Сообщение; продолжаем по последним coords |
| Локация ещё не задана | Онбординг: геолокация или поиск |
| Расчёт | Всегда локальный после известных coords |

## Тестирование

- Ручная проверка popup / dark / light / смена метода.
- Симуляция countdown и смены «следующего» намаза (подмена часов в dev или unit-тесты на `prayer.js` / `badge.js`).
- Отклонение геолокации → поиск города.
- Уведомления on/off и pre-notify.
- Установка unpacked в Chrome/Edge.

## Вне scope (v1)

- Firefox
- Кибла-компас
- Виджет новой вкладки
- Звук азана (только системное notification)
- Аккаунт / синхронизация кроме chrome.storage

## Критерии готовности

1. Папка проекта = `mikat`, название в UI/manifest = Микат.
2. Popup показывает корректные времена для выбранной локации и метода.
3. Badge отражает countdown до следующего намаза.
4. Уведомления работают и полностью отключаются.
5. Тема light/dark и фиолетовый accent в стиле соседних проектов.
6. Геолокация и ручной поиск города работают по сценарию ошибок выше.

# Микат

Расширение Chrome/Edge (Manifest V3): времена намаза, countdown на иконке, уведомления.

## Установка

1. `chrome://extensions` → «Режим разработчика»
2. «Загрузить распакованное» → папка `c:\Users\Admin\projects\mikat`
3. Откройте popup, разрешите геолокацию или найдите город

## Возможности

- Локальный расчёт (библиотека adhan), метод по умолчанию — Muslim World League
- Выбор метода и мазхаба Аср в настройках
- Badge на иконке: `42м` / `2ч` до следующего намаза
- Уведомления (можно выключить) + напоминание за 5/10/15 мин
- Светлая / тёмная тема, фиолетовый акцент

## Разработка

```bash
npm install
npm test
```

Тесты покрывают `lib/badge.js`, `lib/prayer.js`, `lib/storage.js`.
